# ATLAS Recovery Node

Gotowa statyczna witryna WWW #1 do gry OFFLINE.

## Uruchomienie
1. Rozpakuj paczkę.
2. Otwórz `index.html` w przeglądarce.
3. Witryna nie wymaga serwera ani internetu.

## Funkcje
- pełna wersja PL/EN,
- pięcioetapowe odzyskiwanie historii wersji,
- lokalny zapis postępu,
- moduły Disclosure, Audio Notes, Delivery i System Log,
- system podpowiedzi,
- reset lokalnego postępu,
- responsywny interfejs,
- transkrypcja notatki głosowej,
- odtwarzanie treści nagrania przy użyciu głosu systemowego przeglądarki.

## Prawidłowa sekwencja
`v03 → v07 → v11 → v15 → v04-R`

## Publikacja
Cały folder można umieścić na dowolnym hostingu statycznym. Nie zmieniaj nazw `styles.css` i `app.js`, chyba że zaktualizujesz odwołania w `index.html`.
